# الشبكة العربية الصغيرة

مجموعة منتقاة من المدونات والمواقع الشخصية باللغة العربية. مستوحاة من مشروع [Kagi Small Web](https://kagi.com/smallweb).

## واجهة الاكتشاف

تجربة اكتشاف فريدة مستوحاة من Kagi Small Web:

- **نموذج هجين**: نحاول عرض المقال داخل iframe أولاً مثل Kagi، ثم نعرض مقتطف الخلاصة عند حجب التضمين
- **Fallback مفيد**: كل منشور يظل قابلاً للقراءة كرابط ومقتطف حتى لو منع الموقع الأصلي iframe
- **منشور واحد دائماً**: الواجهة تعرض مقالاً واحداً فقط للتركيز على الاكتشاف
- **التالي مباشرة**: زر واحد للانتقال إلى منشور جديد كما في تجربة Kagi Small Web
- **تنويع الخلاصات**: خوارزمية تمنع سيطرة موقع واحد على الصفحة
- **تنقل سهل**: أزرار التنقل + اختصارات لوحة المفاتيح
- **تصميم متجاوب**: يعمل بسلاسة على جميع الأجهزة
- **خطوط محلية**: لا اعتماد على CDN خارجي للخصوصية والأداء

### اختصارات لوحة المفاتيح
- **←/→**: الانتقال للمنشور التالي

## خوارزمية الاكتشاف

يستخدم الموقع خوارزمية ذكية مع تركيز صارم على المحتوى الحديث:

- **أولوية السنة الحالية المطلقة**: منشورات 2026 تُعرض أولاً مع خلط عشوائي
- **فلترة صارمة**: لا منشورات أقدم من سنتين (قبل 2024)
- **تسلسل زمني**: المنشورات الأقدم تُعرض فقط بعد استنفاد منشورات السنة الحالية
- **تحديد يومي**: حد أقصى 3 منشورات لكل مدونة يومياً
- **تعزيز التنوع**: المدونات الأقل نشاطاً تحصل على أولوية أعلى
- **خلط ذكي**: منشورات السنة الحالية مخلوطة عشوائياً (20%)
- **محتوى غني**: 100 منشور متاح للتصفح المطول

## التطوير المحلي

```bash
make venv      # إنشاء البيئة وتثبيت المكتبات
make fonts     # تحميل الخطوط محلياً
make fetch     # جلب الخلاصات
make build     # إنشاء الموقع
make validate  # فحص جودة الخلاصات وحداثتها
make preview   # فتح في المتصفح
make deploy    # تنظيف → خطوط → جلب → بناء → فتح
make clean     # حذف الملفات المُنشأة
```
